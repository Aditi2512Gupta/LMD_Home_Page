# Last Minute Deals (LMD) - Home Page

A standalone, responsive Flutter Home Page application designed for last-minute hotel, resort, camping, and villa stays.

## Features

- **Search & Booking Section**:
  - Interactive destination search bar ("Where are you heading?") with location pin and alerts
  - Check-in & Check-out date selection with interactive date range picker
  - Interactive Guests & Rooms counter modal
- **Category Filter Tabs**:
  - Smooth horizontal scrolling pill chips: `All`, `Hotels`, `Resorts`, `Camping`, `Villas`, `Luxury Villas`
  - Real-time category filtering
- **Stays Sections & Cards**:
  - **Last Minute Hotels**
  - **Last Minute Resorts**
  - **Last Minute Camping**
  - **Last Minute Villas**
  - **Last Minute Luxury Villas**
  - Reusable card components featuring "Live Deal" badges, pastel illustration backgrounds, location pins, star ratings, review counts, and Indian rupee formatting (`₹X,XXX`)
  - Property details and instant booking bottom sheet
- **Brand Messaging Section**:
  - *"India's home — for last minute stays."*
- **Bottom Navigation Bar**:
  - 4 navigation tabs: `Home` (with active dot indicator), `Bookings`, `Saved`, and `Profile`
- **Responsive Design**:
  - Fluid mobile layout
  - Adaptive centered layout on tablet and desktop

## Getting Started

### Prerequisites

- Flutter SDK (3.x or later)
- Dart SDK

### Installation & Run

```bash
# Get dependencies
flutter pub get

# Run on connected device / emulator / browser
flutter run

# Run tests
flutter test

# Build for Web
flutter build web
```
